# Songa Learning Resource Explorer
## Projects Overview
Songa Learning Resoorce Explorer is a webpage built using HTML, css, and JavaScript.
It allowes users to explore learning resources, search for resources, filter them by category, and track their completion progress.
## Project Files
- index.html: Contains the webpage structure.
- style.css: Contains the webpage design and styling.
- script.js: Contains the JavaScript functionality.
- README.md: Explains the project and its features.
## Features
1. Displays seven learning resources.
2. Stores resources in a JavaScript array.
3. Searches resources by title or description.
4. Supports case-insensitive Searching.
5. Filters resource by category.
6. Combines search and category filtering.
7. Displays a message when no resource match.
8. Allows resource to be marked complete or incomplete.
9. Uses event delegation to handle button clicks.
10. Displays the number of respurces matching the filters.
11. Counts completed resources across the entire array.
12. Uses responsive CSS styling.
## How to run the project
1. keep all four files in the same folder.
2. Open index.html in web browser.
3. Search for learning resources.
4. Select a category.
5. Mark resources as completed or incompleted.
